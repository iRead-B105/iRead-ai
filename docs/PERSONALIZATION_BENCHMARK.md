# 개인화 이야기 생성 100건 비교

## 목적

동일한 이야기 맥락에서 일반 LLM 생성과 현재 개인화 파이프라인을 짝지어
비교했습니다. 개인화 파이프라인은 아동 읽기 프로필을 프롬프트에 적용하고,
여러 후보를 Kiwi·G2P로 분석해 선택한 뒤 필요한 경우 국소 교정을 수행합니다.

- 실험 일시: 2026-07-31
- 성공: 100/100
- 모델 호출: 400회
- 이미지 호출: 0회
- 실행 경로: OpenAI 직접 연결(`STORY_PROVIDER=openai`)
- 모델: `gpt-5.4-mini`
- 개인화 후보: 3개 / 일반 후보: 1개
- `visualScene` JSON 생성: 포함

비식별 집계 원본은
[personalization-benchmark-2026-07-31.json](evidence/personalization-benchmark-2026-07-31.json)에
보관합니다. 이 과거 실행은 commit SHA를 기록하지 못했으므로 수치 재현 시
새 실행 결과의 commit·프롬프트 버전도 함께 저장해야 합니다.

평균 생성 시간은 일반 LLM `4.91초`, 개인화 파이프라인 `13.45초`였습니다.
개인화는 평균적으로 더 잘 맞았지만 약 8.5초의 추가 지연이 있었습니다.
이 시간은 GMS 전환 전 직접 연결 결과이므로 GMS 프록시 지연시간 근거로
사용하면 안 됩니다.

## 해석

이 결과는 “현재 자동 평가 기준에서 일반 LLM보다 아동 프로필에 맞는 결과를
더 자주 골랐다”는 근거로 사용할 수 있습니다. 모든 사례에서 좋아진 것은
아니므로 항상 개인화가 우월하다고 표현하면 안 됩니다.

특히 다음 제한이 있습니다.

- Kiwi·G2P 점수는 후보 선택에도 사용되어 완전히 독립된 평가가 아닙니다.
- `FULL_POLICY`로 끝까지 분석된 사례는 19건뿐입니다.
- `COMMON_SURFACE_ONLY` 81건은 공통으로 검증 가능한 표면 특징만 비교한
  부분 신뢰 결과입니다.
- 일반 글 평균은 366.63음절, 개인화 글 평균은 167.55음절로 분량 차이가
  큽니다.
- 엄격한 전체 계약 통과율은 일반 0%, 개인화 4%로 낮았습니다.
- 국소 교정은 100건 모두 시도되었지만 9건만 채택되었습니다.
- 자동 점수는 읽기 부담의 대리 지표이며 교육 효과나 임상적 개선을
  증명하지 않습니다.

따라서 발표·README에서는 평균, 중앙값, 저점, 고점, 승률과 함께 위 제한을
동시에 제시해야 합니다. 다음 단계는 교사·치료사의 블라인드 평가와 실제
아동 읽기 시간·오류율을 별도 지표로 수집하는 것입니다.

## 재현

API를 실제 GMS 글 생성 모드로 실행한 상태에서 다음 명령을 사용합니다.

```powershell
uv run python scripts/run_chapter_comparison_batch.py `
  --case-limit 100 `
  --concurrency 1 `
  --confirm-real-api
```

이 명령은 유료 모델 호출을 수행합니다. 결과는 Git에서 제외된
`local-output/chapter-comparison-batch/`에 저장됩니다. 실패한 실행은
`--resume-dir`로 이어서 실행할 수 있습니다. 새 실행의 `run.json`에는
`storyProvider`가 기록되므로 직접 OpenAI 결과와 GMS 결과를 구분할 수
있습니다. 위 지연시간 수치를 GMS 기준으로 갱신하려면 GMS 모드에서 100건을
새로 실행해야 합니다.
